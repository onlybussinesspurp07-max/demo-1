Staff Feedback Form using Nodejs as backend.

You shouldn't need to install additional packages as everything is preinstalled in repo.

That leaves only requirement being avaibility of nodejs on the system.

It can be downloaded easily.

How to run:

Install nodejs in your system.
Steps to run the server:
First goto backend directory

`cd backend`

Use Node to run server.js file using following command:

`node server.js`

Use the address displayed in terminal to run the server.
